# 标签体系

本文件是 AGIKnowledge 的 canonical tag registry。整理新笔记或批量规范标签时，先查本文件；只有现有标签无法表达关键知识轴时，才新增标签。

## 命名规则

- 使用小写英文、数字、短横线和 `/`，例如 `topic/3d-reconstruction`。
- 不使用中文、emoji、大小写变体、空格、下划线或单复数混用。
- 标签表达“检索维度”，不是摘要关键词；单篇笔记通常 5-8 个标签。
- 每篇正式笔记必须包含 1 个 `layer/*` 和至少 1 个 `type/*`；主类型放在最前，`type/moc` 可作为综述/索引的第二类型。
- 会议/年份统一写成 `venue/cvpr-2025`，不要写 `CVPR2025`、`cvpr25`。
- 工具、机构、模型名只有在它们是稳定检索维度时才作为 `entity/*` 使用。
