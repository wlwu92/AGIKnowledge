# AVS — Uber 自动驾驶可视化标准

## 用途

AVS（Autonomous Visualization System）是 Uber Advanced Technologies Group（ATG）于 2019 年开源的标准和 Web 工具包，用于描述、可视化和交互自动驾驶车辆的感知、运动与规划数据。它将可视化抽象为标准化数据格式与组件，使自动驾驶工程师无需深入计算机图形学即可构建调试工具。

## 核心能力

### XVIZ — 数据规范
- **流式场景描述**：提供基于"流"的场景随时间变化的数据视图，配合声明式 UI 显示系统
- **原始数据类型**：LiDAR 点云、摄像头图像、障碍物包围盒、轨迹、车辆速度等
- **层级组织**：Stream 按层级组织，携带样式、变换和 UI 面板元数据

### streetscape.gl — 前端工具包
- 基于 React/WebGL 的组件工具包，消费 XVIZ 数据
- 提供即插即用组件：3D 视口、图表、表格、视频等
- 处理时间同步、坐标系变换、相机控制和动态样式

### 设计特点
- **平台与数据解耦**：数据层与底层平台明确分离
- **紧凑传输格式**：快速传输与处理
- **基于 Web**：支持快速迭代、协作和跨团队集成
- **实时回放**：支持数十万几何体的大场景回放
- **可组合可扩展**：团队可根据工作流定制可视化体验

## 使用方式

AVS 是开放标准，任何自动驾驶团队都可采用 XVIZ 数据格式来描述场景，并使用 streetscape.gl 组件库渲染可视化界面。Uber 在日志查看、开发环境、地图维护等场景均有用例，也曾被 Voyage 和 Applied Intuition 等公司采用。

## 适用边界

- 专注于**数据可视化层**，不涉及感知、规划等核心自动驾驶算法
- 数据格式（XVIZ）与渲染组件（streetscape.gl）可独立使用
- 潜在应用领域：自动驾驶、无人机、机器人、卡车、AR/VR
- 项目现状：2019 年开源后更新频率不明，引入前需确认社区活跃度
