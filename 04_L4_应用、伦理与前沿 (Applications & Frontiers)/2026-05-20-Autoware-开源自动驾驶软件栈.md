# Autoware — 开源自动驾驶软件栈

## 用途

Autoware 是 Autoware Foundation 治理下的**世界领先的开源自动驾驶软件项目**，提供完整的自动驾驶软件栈，基于 ROS 2 构建。最新稳定版 v1.8.0（2026-05-04）。

## 核心能力

完整覆盖 L4 级自动驾驶所需的核心功能：

- **Localization**：车辆定位
- **Object Detection**：障碍物感知
- **Route Planning**：路径规划
- **Control**：驾驶控制执行

## 架构设计

Autoware 采用多仓库组织：

| 仓库 | 职责 |
|------|------|
| **autoware**（本仓库） | 元仓库，包含 `.repos` 文件用于构建工作空间，适合频繁 fork |
| **autoware_core** | 高质量、稳定的 ROS 2 自动驾驶核心包 |
| **autoware_universe** | 实验性、前沿的 ROS 2 包，适合研究者扩展功能 |
| **autoware_launch** | 节点配置与参数定义 |
| **autoware-documentation** | 面向用户和开发者的集中文档 |

架构基于 **ROS 2**（历史版本 Autoware.AI 基于 ROS 1，已于 2022 年停止维护）。

## 使用方式

```
# 通过 .repos 文件构建工作空间
vcs import < autoware.repos
```

采用 Dockerfile（57.5%）、Shell（29.0%）、HCL/Terraform（13.5%）构建基础设施。社区通过 Discord、Twitter/X、LinkedIn 交流，多个 Working Group 管理持续开发。

## 适用边界

- 适用于**完整的自动驾驶系统开发与研究**，涵盖从实车部署到仿真验证
- 不适合需要轻量级或非 ROS 生态的嵌入式场景
- autoware_core 提供稳定 API，适合产品级集成；autoware_universe 适合学术研究与功能实验
- 需要 Ubuntu + ROS 2 环境支持
