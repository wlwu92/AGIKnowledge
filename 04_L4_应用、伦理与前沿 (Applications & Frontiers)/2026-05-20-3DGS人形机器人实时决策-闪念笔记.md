# 3DGS 在人形机器人实时决策中的应用 — 闪念笔记

> 核心论点：3DGS 是唯一同时满足**可微渲染 + 显式可编辑 + 实时渲染 + 逼真渲染**四个条件的场景表示。这让人形机器人的决策逻辑可以走一条新路线：将代价函数定义在**渲染图像空间**而非低维状态空间，信息无损，且天然适配高维（30+ DOF）动作空间的优化。

---

## 背景：为什么是 3DGS？

| 条件 | 3DGS | NeRF/隐式场 | 点云 | 三角网格 | TSDF |
|------|------|-------------|------|----------|------|
| 可微渲染 | ✅ 原生 | ✅ 但极慢 | ❌ | ⚠️ 需额外渲染器 | ❌ |
| 显式可编辑 | ✅ 移动/删/改单个 Gaussian | ❌ MLP 权重不可直接编辑 | ✅ | ⚠️ 拓扑约束 | ❌ |
| 实时渲染 | ✅ >30fps | ❌ <1fps | N/A | ✅ | N/A |
| 逼真渲染 | ✅ SOTA | ✅ SOTA | ❌ | ⚠️ 依赖纹理质量 | ❌ |

NeRF 可微但不可编辑，点云可编辑不可微，只有 3DGS 同时拥有全部四条。

---

## 机制一：可微视觉 MPC（核心机制）

将 MPC 的代价函数从低维状态空间（关节角、末端位姿）提升到**渲染图像空间**——信息无损，维度可降。

```
工作流：
1. 前馈 3DGS 重建当前场景（~22fps）
2. 机器人本体建模为"可变形 Gaussians"（随关节角变化位姿）
3. 候选动作序列（未来 T 步关节轨迹）→ 正运动学 → 预测未来各时刻机器人姿态
4. 更新场景中机器人 Gaussians → 渲染预测的未来视角图像
5. 在图像空间计算代价（手-物对齐、障碍物重叠、社交距离）
6. 损失对动作参数求导 → 反向传播通过可微渲染器 → 梯度更新动作序列
7. 执行第一帧动作，滚动优化
```

**与人形机器人适配点：**
- 30+ DOF 的高维动作空间 → 传统 MPC 计算爆炸
- 视觉 MPC 把优化空间压缩到**任务相关的图像特征空间**（如只对"手部像素位置"和"目标像素位置"之差做优化）
- 全身运动协调天然被渲染器捕捉（自遮挡、自碰撞在渲染时自动体现）

**类比：** AlphaGo 的 MCTS + 价值网络，棋盘换成 3D Gaussian 场景，"落子"换成关节运动，"胜负"换成渲染图像与目标图像的相似度。

---

## 机制二：What-If 场景推演（显式假设检验）

人形机器人在复杂环境中经常面临离散决策分叉（"从左边绕还是右边绕？"）。

```
工作流：
1. 机器人到达 T 型路口
2. 复制当前 3DGS 场景 → 创建两份推演副本
3. 推演 A：沿左侧路径移动机器人 Gaussians → 重渲染 → 量化"侵入人体舒适区"的成本
4. 推演 B：沿右侧路径移动机器人 Gaussians → 重渲染 → 量化"时间成本"
5. 比较两个假设的联合代价 → 做出决策
```

与传统方法的本质区别：

| 维度 | 传统方法 | 3DGS 推演法 |
|------|---------|------------|
| 场景理解 | 几何体素/语义标签 | 完整视觉场景（光照、纹理、半透明物体） |
| 假设验证 | 二进制碰撞检测 | 连续代价函数（越靠近代价越高） |
| 决策依据 | "会撞 / 不会撞" | "渲染出来看起来怎样" |
| 人机交互 | 距离阈值 | 视线遮挡、社交距离、姿态可读性 |

## 机制三：视角归因（Perspective-Taking）

人形机器人需要与人类共享物理空间。3DGS 让机器人可以**渲染出人类视角的画面**。

```
应用：
1. 3DGS 场景中包含人类模型
2. 将渲染相机放到人类头部位置 → 渲染"人类看到的画面"
3. 推理：人类是否能看到我操作的物体？我的意图在人类视角中是否明确？
4. 决策优化：调整站位 / 动作速度
```

为什么非 3DGS 不可？点云/Mesh 渲染质量不足以支撑"视线可读性"这类微妙判断，NeRF 渲染一次需要秒级——人形机器人交互是毫秒级的。

---

## 机制四：场景记忆 + 长时决策

3DGS 作为场景记忆的压缩形式，支持长时任务（"去卧室拿钥匙再回厨房"）。

```
1. 探索新房间 → 多视角采集 → 前馈 3DGS → 压缩存储（~几 MB/房间）
2. 需要回这个房间时：加载 3DGS → 渲染成本地图 → 渲染目标物体位置
3. 实时观测与记忆对比 → 检测场景变化 → 重新规划
```

对比传统方案：
- 关键帧位姿 + 稀疏点云 → 无法回答"这个物体长什么样"
- 3DGS 记忆 → 完整视觉信息，可在任意视角下查询

## 全景对比：3DGS vs. 现有方案在各决策任务

| 决策任务 | 传统做法 | 3DGS 做法 | 3DGS 是否有本质优势 |
|---------|---------|-----------|-----------------|
| 抓取规划 | GraspNet 在点云上预测 | 可微渲染优化手-物对齐 | ⚠️ 互补，非替代 |
| 避障规划 | 代价地图 + A* | 渲染深度 overlap + 梯度优化 | ❌ 传统方法更快更可靠 |
| **社会导航** | 社交距离势场 | **视角归因 + 意图可读性** | ✅ **3DGS 独有优势** |
| **任务规划（长时）** | PDDL / LLM symbolic | **场景记忆 + 视觉查询** | ✅ **3DGS 信息密度高** |
| **人机协作动作协调** | 显式状态机 | **共同视觉空间推理** | ✅ **3DGS 独有优势** |
| 全身运动规划 | Kinematic RRT | 渲染-based 碰撞代价 | ❌ 计算开销大，无优势 |

## 工程化缺口

| 缺口 | 描述 | 难度 |
|------|------|------|
| 可微正运动学 | 关节角→Gaussian 位姿的可微映射不存在 | 🔴 高 |
| 反向传播效率 | 通过可微光栅化器传梯度仍在 10-100ms 级 | 🔴 高 |
| 场景快照克隆 | 快速拷贝场景用于推演，当前不支持 | 🟡 中 |
| 编辑后物理合理性 | 移动 Gaussian 不自动遵守物理约束 | 🟡 中 |
| 3DGS 场景更新 | 增量式更新尚未成熟 | 🔴 高 |
| 记忆检索 | 语义索引 3DGS 场景需额外模块 | 🟡 中 |

### 核心相关工作

| 工作 | 发表 | 与本思路的关联 |

| **[[2026-05-20-Dr-Robot-可微机器人渲染\|Dr. Robot]]** (Differentiable Robot Rendering) | arXiv 2410.13851, Columbia & Stanford | 将机器人建模为可变形 Gaussians，通过可微渲染实现像素级控制优化，与"机制一"直接对齐 |
| **Gaussian Splatting Visual MPC** | ICRA 2025, arXiv 2410.09740 | 在 3DGS 表示上学习视觉动力学模型，通过 MPC 操控颗粒介质，验证了可微渲染 + MPC 的可行性 |
| **BEINGS** (Bayesian Embodied Image-goal Navigation) | ICRA 2025 | 将 3DGS 作为场景先验，在 MPC 框架中做图像目标导航，贝叶斯更新动态调整策略 |
| **Physically Embodied Gaussians** | NVIDIA Technical Blog 2025 | 双表示架构（Particles + Gaussians），可微渲染持续修正物理仿真，形成~30Hz 的闭环世界模型 |
| **GAF: Gaussian Action Field** | arXiv 2506.14135, 2025 | 3DGS + 可学习运动属性，同时建模动态场景和动作推理，V-4D-A 范式 |
| **GSMem: 3DGS as Persistent Spatial Memory** | arXiv 2603.19137, Mar 2026 | 3DGS 作为持久空间记忆，VLM 评分 + GS 覆盖熵的混合探索策略，与"机制四"高度吻合 |
| **MAGICIAN** (3D Active Mapping) | CVPR 2026 Oral, arXiv 2603.22650 | "Imagined Gaussians"——用 occupancy + 3DGS 让机器人"想象"未见区域，做长程轨迹规划，与"机制二"直接相关 |
| **Splatting Physical Scenes** | arXiv 2506.04120, Google DeepMind + UCL | Hybrid (3DGS + Mesh)，可微渲染 + 可微物理 (MuJoCo MJX) 端到端优化 |
| **GraspSplats** | CoRL 2025 | 3DGS + 深度监督 + 实时抓取采样，动态/铰接物体操作 |
| **ArtGS** | IROS 2025 | 3DGS + 可微渲染优化铰接物体参数 |
| **Forecast-GS** | arXiv 2605.11144, May 2026 | 预测任务完成后的 3D 状态，评估候选动作的可行性 |

### 未覆盖的空白（机会区域）

1. **人形机器人专用**（双足全身）：已有工作集中在机械臂抓取，尚无面向双足人形机器人全身协调的 3DGS 决策方案
2. **视角归因（Perspective-Taking）**：公开文献中无类似思路——"用 3DGS 渲染他人视角来做社交决策"目前是空白
3. **3DGS + 推演式 MCTS**：MAGICIAN 做"想象"但目标是建图探索，不是离散动作分支的假设检验决策

## 值得优先尝试的方向

| 时间线 | 方向 | 简述 |
|--------|------|------|
