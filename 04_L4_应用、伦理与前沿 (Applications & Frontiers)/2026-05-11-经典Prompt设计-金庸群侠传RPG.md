# 经典 Prompt 赏析：金庸群侠传 RPG

> **作者**: 蝈蝈俊 (cnblogs)
> **核心**: 将 ChatGPT 转化为金庸武侠互动 RPG 游戏的 Prompt 设计案例

## Prompt 设计要点

| 技巧 | 说明 |
|------|------|
| **清晰角色定义** | GPT 定位为"金庸群侠传 RPG 引擎"，用户为玩家/故事叙述者 |
| **结构化输出** | 每轮交互强制三部分组成：场景描述 + 4 个选项 + 场景图片 |
| **约束与创意平衡** | 基于 13 部金庸小说约束剧情，同时允许用户自由探索的非线性结局 |
| **关键点重复强调** | 配图指令重复出现，提高遵循概率 |
| **内容护栏** | 色情/暴力选项导向"魔教"路线并面临正道围攻，用游戏内机制替代硬性禁止 |
| **开放式结局** | 无单一胜利条件，支持不同玩家目标（婚姻/武功/仕途等）|

## 技术分析

- 使用 `scene / choices / scene image` 三段式结构保证交互一致性
- 通过格式约束（每次 4 个选项 + 必须配图）创造"有边界的沙盒"
- 文化特定性（金庸小说）是 Prompt 差异化的关键
