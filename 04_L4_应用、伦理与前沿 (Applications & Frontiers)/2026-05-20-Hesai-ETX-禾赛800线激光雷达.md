# 禾赛 ETX — 真800线车规级激光雷达

## 概述

2025 年 9 月，禾赛科技在 IAA Mobility 慕尼黑国际车展上发布新一代高性能激光雷达 **ETX**，采用第四代自研芯片平台，实现 **真800线**（非插值）、**400米@10%反射率** 的行业领先性能，专为 L3/L4 自动驾驶打造，计划 2026 年量产交付。

## 核心能力

| 指标 | 参数 |
|------|------|
| 线数 | 真800线（非插值） |
| 角分辨率 | 最高 0.05° × 0.025° |
| 测距 | 400 米 @10% 反射率 |
| 视窗高度 | 32 mm（较同类减少 35%） |
| 功耗 | 11W |
| 人眼安全 | Class 1 |

## 核心技术

ETX 基于禾赛**第四代芯片平台**，实现三大模块 100% 自主可控：

- **光矢量芯片 (PVT)** — 纳米级光刻工艺定制高功率 VCSEL 阵列，提升 30% 测距能力
- **光子隔离技术 (API)** — 独立可寻址收发器件，误报率降低 95%
- **波形解码引擎 (IPE)** — 246 亿次/秒超频采样，环境噪点滤除率超 99.9%

## 量产计划

- **2026 年启动批量交付**
- 已获全球顶级车厂海外量产车型及国内领先车企新车型定点

## 适用边界

- 主要面向 L3/L4 级自动驾驶的前向主雷达
- 同期发布的 FTX（纯固态补盲雷达）和 ATX（L2 级别）形成产品矩阵
- 价格和具体上车车型尚未公开
