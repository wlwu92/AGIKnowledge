# GR00T-WholeBodyControl — NVIDIA 人形机器人全身控制平台

**NVlabs** | GitHub: [NVlabs/GR00T-WholeBodyControl](https://github.com/NVlabs/GR00T-WholeBodyControl)

## 用途

NVIDIA 的统一平台，用于开发和部署高级人形机器人控制器。覆盖从运动跟踪基础模型到实时交互运动生成的完整管线。

**License**: Apache 2.0（源码）/ NVIDIA Open Model License（模型权重）

## 核心能力

### GEAR-SONIC — 人形行为基础模型
- 将运动跟踪作为可扩展训练任务，从大规模人体运动数据学习核心运动技能
- **Bones-SEED 数据集**：142K+ 片段，约 288 小时生产级 Mocap 数据
- 支持 VR 遥操作（PICO 头显）、运动学规划（键盘/手柄）、Sim-to-Real 部署
- 论文：SONIC — [arXiv 2511.07820](https://arxiv.org/abs/2511.07820)
- 模型权重：Hugging Face [nvidia/GEAR-SONIC](https://huggingface.co/nvidia/GEAR-SONIC)

### Decoupled WBC
- 下肢 RL + 上肢逆运动学的双组件控制器
- 用于 NVIDIA GR00T N1.5 和 N1.6 模型

### MotionBricks（SIGGRAPH 2026）
- 详见 [[2026-05-23-MotionBricks-实时模块化运动生成.md|MotionBricks 笔记]]
- 实时潜空间运动生成（15,000 FPS），零样本迁移到新任务

## 技术栈

| 组件 | 详情 |
|------|------|
| 语言 | Python (56.6%), C++ (38.6%) |
| 训练 | PPO via Isaac Lab, `accelerate` 分布式训练 (64+ GPU) |
| 仿真 | MuJoCo, Isaac Lab v2.3.2 |
| 部署 | C++ 推理栈 + ZMQ v4 通信 |
| 硬件 | Unitree G1, PICO VR 头显 |
| 数据 | Bones-SEED 数据集 (Hugging Face) |

## 适用边界

- 人形机器人全身控制 > 传统分体式控制（上下身分离）
- 需要大规模 Mocap 数据驱动的运动策略学习
- 适用于常见人形机器人平台（Unitree G1 等）
- 需要 NVIDIA Isaac Sim/Lab 仿真环境支持
