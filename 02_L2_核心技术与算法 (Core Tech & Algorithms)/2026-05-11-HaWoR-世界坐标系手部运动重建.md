# HaWoR: World-Space Hand Motion Reconstruction from Egocentric Videos

> **作者**: Jinglei Zhang (SJTU), Jiankang Deng (Imperial), Chao Ma (SJTU), Rolandos Alexandros Potamias (Imperial)
> **会议**: CVPR 2025 Highlight
> **论文**: arxiv 2501.02973
> **代码**: github.com/ThunderVVV/HaWoR

## 核心贡献

从第一人称（egocentric）视频中重建**世界坐标系**下的双手运动。区别于传统方法只输出相机坐标系下的结果。

## 方法要点

- 结合 **DROID-SLAM** 估计相机姿态 + **Metric3D** 估计深度 → 将手部从相机坐标系转换到世界坐标系
- 使用 MANO 模型作为手部参数化模型
- 支持在 HOT3D 和 DexYCB 数据集上评估

pip install -r requirements.txt
