# SMPL — Skinned Multi-Person Linear Model

## 概述

MPII 开发的逼真 3D 人体模型，基于蒙皮和混合形状，从数千个 3D 人体扫描中学习得到。参数化人体模型的行业标准。

**论文**: SIGGRAPH Asia 2015, ACM Trans. Graphics (Loper et al.)

## 模型特点

- **姿态依赖混合形状**: 姿态旋转矩阵元素的线性函数
- **身份依赖混合形状**: 最多 300 个形状分量
- **男/女/中性版本**: 三种性别版本
- **支持线性及双四元数蒙皮**
- **动态软组织变形**
- **Maya/Python/Unity/Blender/Unreal 插件**

## 模型系列

| 模型                | 特点              |
| ----------------- | --------------- |
| **SMPL**          | 基础人体模型          |
| **MANO / SMPL+H** | 加可关节手部          |
| **SMPL-X**        | 加可关节手部和面部表达     |
| **STAR**          | 紧凑模型，稀疏局部矫正混合形状 |
| **SUPR**          | 因式分解表示，含足部模型    |
| **SKEL**          | 含皮肤和骨骼网格的生物力学模型 |
