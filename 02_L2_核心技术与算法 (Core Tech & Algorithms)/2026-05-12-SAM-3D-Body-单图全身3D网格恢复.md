# SAM 3D Body — 单图全身 3D 网格恢复

## 概述

Meta Superintelligence Labs 提出的单图全身体网格恢复模型，属于 SAM 3D 系列。能从单张图像恢复包含身体、脚、手的全身 3D 人体网格。

**论文**: arXiv 2602.15989

## 核心技术特点

- **Momentum Human Rig (MHR)**: 新的参数化网格表示，解耦骨骼结构和表面形状
- **可提示架构**: 支持 2D 关键点和 mask 等辅助提示
- **编码器-解码器架构**: 包含可选的手部解码器用于手部细化
- **多阶段训练**: 可微优化、多视图几何、密集关键点检测

## 性能

| 指标 | DINOv3-H+ (840M) | ViT-H (631M) |
|------|------------------|--------------|
| 3DPW MPJPE | 54.8 | 54.8 |
| EMDB MPJPE | 61.7 | 62.9 |
| RICH PVE | 60.3 | 61.7 |

## 使用

```python
estimator = setup_sam_3d_body(hf_repo_id="facebook/sam-3d-body-dinov3")
outputs = estimator.process_one_image(img_rgb)
```

检查点托管在 Hugging Face，支持 DINOv3-H+ 和 ViT-H 两种规格。
