# SAM 3D Body — 单图全身 3D 网格恢复

## 概述

Meta Superintelligence Labs 提出的单图全身体网格恢复模型，属于 SAM 3D 系列。能从单张图像恢复包含身体、脚、手的全身 3D 人体网格。

**论文**: arXiv 2602.15989

## 核心技术特点

- **Momentum Human Rig (MHR)**: 新的参数化网格表示，解耦骨骼结构和表面形状
- **可提示架构**: 支持 2D 关键点和 mask 等辅助提示
- **编码器-解码器架构**: 包含可选的手部解码器用于手部细化
- **多阶段训练**: 可微优化、多视图几何、密集关键点检测

## 推理管线性能分析

### MHR Forward Kinematics 瓶颈

在 `sam_3d_body/models/heads/mhr_head.py` 中，`MHRHead.mhr_forward()` 调用 `self.mhr(shape_params, model_params, expr_params)` 时，MHR 内部执行**骨骼树的前向运动学计算**（joint_parameters → skeleton_state），这是推理管线中的一个顺序计算瓶颈。

### 调用链

```
sam_3d_body/models/heads/mhr_head.py
  → MHRHead.mhr_forward()
    → self.mhr(shape_params, model_params, expr_params)
      → mhr/mhr.py: MHR.forward()
        → joint_parameters_to_skeleton_state()
          → pymomentum/torch/character.py: Skeleton.local_skeleton_state_to_skeleton_state()
            → pymomentum/backend/skel_state_backend.py: global_skel_state_from_local_skel_state_impl()
```

### 瓶颈原因

127 个关节的前向运动学存在**父子依赖**——每个关节的世界变换必须等其父关节计算完成。当前实现使用**倍增算法（binary lifting / prefix scan）** 将串行步数从 O(D) ≈ 30 降低到 O(log D) ≈ 7，但由于实现为 Python JIT 循环 + 逐层 CUDA kernel launch + 显存读写，仍有明显的延迟开销。
