# HSMR — Reconstructing Humans with a Biomechanically Accurate Skeleton

**CVPR 2025 Oral (Top 3.3%)** | arXiv: [2503.21751](https://arxiv.org/abs/2503.21751) | Project: [isshikihugh.github.io/HSMR/](https://isshikihugh.github.io/HSMR/)

## 概述

将生物力学校骨骼模型引入人体网格恢复的端到端框架。不同于传统 SMPL 系的简化非解剖学骨架，HSMR 使用 [[2026-05-23-SKEL-生物力学参数化人体模型.md|SKEL]] 作为基础表示，从单目图像/视频重建具有解剖学合理性的 3D 人体。

**License**: MIT

## 核心贡献

- **生物力学准确骨架**：首次在端到端 HMR 流程中使用 SKEL 模型，输出含解剖学关节和骨骼网格的 3D 人体
- **SKELify 优化管线**：根据可信的 2D 关键点优化 SKEL 参数
- **图像与视频双支持**：同时支持单帧图像和时序视频输入
- **完整开源**：包括 demo、评估、训练代码和 Colab/HuggingFace 交互 demo

## 方法机制

| 组件 | 细节 |
|------|------|
| 骨架模型 | [[2026-05-23-SKEL-生物力学参数化人体模型.md|SKEL]]（生物力学准确） |
| 基础框架 | 继承 HMR2.0/4D-Humans、SKEL、SMPLify-X、SPIN、ProHMR |
| 2D 关键点 | ViTPose |
| 目标检测 | Detectron2 |
| 渲染 | 支持骨骼网格渲染，可选 `--ignore_skel` 参数控制性能 |

## 判断与局限

- 在 CVPR 2025 获得 Oral（Top 3.3%），证明社区对解剖学 HMR 方向高度认可
- SKEL 模型本身为非商用许可，可能限制工业应用
- 目前仅使用 SKEL 作为骨架表示，未集成全身（手+脸）能力
