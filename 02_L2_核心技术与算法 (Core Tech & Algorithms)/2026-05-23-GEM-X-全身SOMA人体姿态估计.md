# GEM-X — Monocular Whole-Body 3D Human Pose Estimation with SOMA

**与 GEM 同属 ICCV 2025 Highlight 项目** | arXiv: [2505.01425](https://arxiv.org/abs/2505.01425) | Code: [NVlabs/GEM-X](https://github.com/NVlabs/GEM-X)

## 概述

GEM 项目的全身体（含手+脸）变体，使用 [[2026-05-12-SOMA-X-统一参数化人体模型.md|SOMA]] 参数化身体模型输出 77 关节的全身运动。面向 monocular video，同时恢复相机空间和世界空间的 3D 人体姿态与轨迹。

**License**: Apache 2.0

## 核心能力

- **77 关节 SOMA 身体模型**：覆盖身体、双手、面部完整关节
- **自带 2D 关键点检测器**：针对 SOMA 骨架专门训练
- **相机空间与世界空间运动恢复**：支持动态相机场景下的全局轨迹估计
- **人形机器人重定向**：支持到 Unitree G1 的 SOMA Retargeter
- **ONNX/TensorRT 推理加速**：支持工业级部署

## 判断与局限

- 与 GEM 共用同一篇论文但提供不同能力，适合需要全身姿态估计的场景
- SOMA Retargeter → 人形机器人这一链路有明确的应用场景（参见 [[2026-05-23-GR00T-人形机器人全身控制平台.md|GR00T-WholeBodyControl]]）
- 仅有姿态估计能力，不支持运动生成（需配合 GEM 使用）
