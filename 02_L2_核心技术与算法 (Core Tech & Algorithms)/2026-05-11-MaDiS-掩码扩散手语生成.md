# MaDiS: 掩码扩散手语生成

> **MaDiS: Taming Masked Diffusion Language Models for Sign Language Generation**
>
> **作者**: Ronglai Zuo, Rolandos Alexandros Potamias, Qi Sun, Evangelos Ververas, Jiankang Deng, Stefanos Zafeiriou
> **时间**: 2026 (arXiv 2601.19577)

## 核心贡献

将 [[2026-05-11-HaWoR-世界坐标系手部运动重建|HaWoR]] 的手部运动重建能力用于**手语生成**（Sign Language Generation），提出掩码扩散语言模型，支持双向上下文建模和并行多 token 生成。

## 方法要点

- **掩码扩散语言模型**替代传统自回归方法
- **三层次跨模态预训练**：token 级＋隐空间级＋3D 物理空间级
- **Mixture-of-Parts 嵌入层**：通过可学习门控和优化码本融合不同手部部位的 token 信息
- 推理吞吐提升 **~40%**，延迟降低 **~30%**
