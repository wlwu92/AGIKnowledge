# Diff3R — Feed-forward 3DGS with Uncertainty-aware Differentiable Optimization

## 概述

**Diff3R: Feed-forward 3D Gaussian Splatting with Uncertainty-aware Differentiable Optimization**（arXiv 2026）由 TUM（Yueh-Cheng Liu, Matthias Nießner, Angela Dai）与 Huawei Technologies（Jozef Hladký）合作提出。核心思路是将可微 3DGS 优化层直接嵌入前馈训练循环，让网络预测的 Gaussians 成为**测试时优化的最优起点**，而非直接输出零样本结果。

## 核心贡献

1. **可微优化层**：在前馈 3DGS 模型的训练循环中插入可微优化层，弥合前馈预测与测试时优化之间的鸿沟
2. **高效反向传播**：通过隐函数定理和矩阵自由 PCG 求解器实现高效梯度计算，避免对迭代优化步骤的完整反向传播
3. **不确定性感知自适应约束**：学习的不确定性权重充当优化的自适应近端约束，防止在欠约束区域过拟合上下文视图，提升对离群值的鲁棒性
4. **模型无关设计**：优化层可无缝集成到现有前馈 3DGS 架构（有/无位姿方法均可），提升测试时优化结果

## 方法机制

```
输入稀疏上下文视图
        ↓
前馈网络 → 初始高斯参数 Θ₀
        ↓
可微优化层（隐式梯度 + PCG 求解器）
        ↓
优化后高斯参数 Θ*
        ↓
可微光栅化 → 新视角渲染
```

不确定性权重 Λ 约束参数在优化过程中的"允许变化范围"，在稀疏视图下防止过拟合。

## 判断与局限

- **优势**：模型无关设计使其可加速现有方法的测试时优化收敛，不确定性机制提升了鲁棒性
- **局限**：训练中需要额外的优化层计算（PCG 求解器），推理成本高于纯前馈方法；在不同场景类型上的泛化边界尚待探索
