# Anny — 全年龄段可微分人体模型

## 概述

NAVER 开发的 PyTorch 可微分人体网格模型，覆盖从婴儿到老年人的全年龄段人体形状表示。

**论文**: arXiv 2511.03589 (Brégier et al., 2025)
**License**: Apache-2.0

## 核心特点

- **全年龄段覆盖**: 区别于 SMPL 等仅关注成人的模型
- **完全可微**: 纯 PyTorch 实现，适合深度学习管线
- **统一拓扑和参数空间**: 共享底层结构简化跨年龄比较和动画
- **模块化**: 单独的手部和面部子模型
- **多拓扑支持**: v0.2 引入多拓扑，v0.3 引入 SMPL-X 拓扑（非商业）

## 差异化优势

- **开源免费**: SMPL 系列需要许可，Anny 完全 Apache-2.0
- **全年龄段**: 其他模型主要使用成人扫描数据训练
- **基于 MakeHuman/MPFB2 生态**: 基于 CC0 许可的社区资源

## 安装

```bash
pip install anny[warp,examples]
```

Gradio 交互式演示: `anny.examples.interactive_demo`
