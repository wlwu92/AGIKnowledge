# DETR — 端到端目标检测变换器

## 概述

DETR (DEtection TRansformer) 由 Facebook AI（Nicolas Carion、Francisco Massa 等）提出，将目标检测重构为直接集合预测问题。它使用 Transformer 编码器-解码器架构和二分图匹配损失，消除了非极大值抑制（NMS）和锚框等手工设计组件。

## 核心贡献

- **首个端到端 Transformer 检测器**：无需 NMS、锚框等手工组件，简化检测流程
- **二分图匹配损失**：通过 Hungarian 算法实现预测与真值的一对一唯一匹配
- **Object queries 机制**：固定小集合的可学习查询，在解码器中并行推理目标关系与全局上下文
- **自然扩展至全景分割**：统一框架同时支持目标检测和全景分割

## 方法机制

1. CNN 骨干（ResNet）提取图像特征
2. Transformer 编码器对特征进行全局关系建模
3. Transformer 解码器以 object queries 为输入，利用注意力交互输出检测结果
4. FFN 将解码器输出映射为分类概率和边界框
5. Hungarian 匹配损失实现端到端训练

## 判断与局限

- 在 COCO 上取得与 Faster R-CNN 相当的精度和速度
- 小目标检测性能较弱（受限于 Transformer 特征分辨率）
- 训练收敛速度较慢（比 Faster R-CNN 需要更多 epoch）
- 后续工作（Deformable DETR、RT-DETR 等）针对这些问题进行了改进
