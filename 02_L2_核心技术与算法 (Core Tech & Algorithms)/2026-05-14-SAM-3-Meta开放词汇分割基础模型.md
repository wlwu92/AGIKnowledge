# SAM 3 — Meta 开放词汇分割基础模型

> **SAM 3: Segment Anything with Concepts**
>
> **出品**: Meta Superintelligence Labs (2025)
> **代码**: https://github.com/facebookresearch/sam3
> **协议**: Apache 2.0

## 用途

SAM 3 是 Meta 的统一基础分割模型，支持图像和视频的 **开放词汇文本提示分割**。用户输入自然语言短语（如"a player in white"），模型自动分割场景中所有匹配实例。

## 核心能力

- **开放词汇文本提示**：比 SAM 1/2 的点/框/掩码提示更进一步，支持任意概念的文本描述
- **穷举实例分割**：对同一概念自动找出画面中所有匹配对象
- **视频追踪分割**：检测器+追踪器双组件设计，支持跨帧一致分割
- **Presence Token**：提升语义相近文本提示的区分能力（如两个相似的短语）

## 架构

- **参数量**: 848M
- **检测器**：基于 DETR，以文本、几何、图像示例为条件
- **追踪器**：继承 SAM 2 的 transformer encoder-decoder 架构
- **共享视觉编码器**：检测器和追踪器共享 backbone
- 解耦的检测器-追踪器设计"最小化任务干扰，随数据规模高效扩展"

## 与前代对比

| | SAM 1 & 2 | SAM 3 |
|---|---|---|
| 提示方式 | 点/框/掩码 | + 开放词汇文本提示 |
| 概念级分割 | 不支持 | 穷举所有匹配实例 |
| 视频追踪 | SAM 2 引入 | 解耦检测器-追踪器 |
| 数据规模 | — | 400 万+概念自动标注 |

## 使用方式

1. 环境: Python 3.12+, PyTorch 2.7+, CUDA 12.6+
2. 安装: `pip install -e .`
3. 获取权重: HF 认证后 `hf auth login`
4. 推理: 通过 `Sam3Processor` 设置图像和文本提示，获取 masks/boxes/scores
5. 可选: `flash-attn-3`、`einops`、`ninja` 加速推理

## 适用边界

- **性能**: 在新 SA-Co 基准（27 万独特概念）上达到人类水平的 75-80%
- **局限**: 需要 GPU（CUDA 12.6+），权重需申请访问权限
- **后续**: SAM 3.1（Object Multiplex）已发布，支持共享内存多目标联合追踪
