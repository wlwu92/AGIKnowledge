# SOMA-X — 统一参数化人体模型中间表示

## 概述

NVIDIA Labs 开发的规范人体拓扑与骨架系统，作为多种参数化人体模型之间的通用桥接层。解决 SMPL、SMPL-X、MHR、Anny 等模型之间拓扑和参数化不兼容的问题。

**License**: Apache-2.0

## 核心能力

- **统一动画管线**: 任何支持的模型通过单一管线驱动
- **端到端可微**: 基于 NVIDIA Warp，GPU 加速
- **统一姿态矫正**: 姿态依赖变形在所有支持模型上通用
- **格式转换**: SMPL ↔ SOMA、MHR ↔ SOMA 的双向转换

## 支持的模型

| 模型 | 来源 |
|------|------|
| MHR | Facebook Research |
| Anny | NAVER |
| SMPL/SMPL-X | MPII/Tübingen |
| SOMA-shape | 自研 PCA 模型 |
| GarmentMeasurement | mbotsch |

## 性能

AMASS → SOMA 转换在 A100 上可达 17393 FPS，平均误差 0.53cm。

安装: `pip install py-soma-x`
