# Dyn-HaMR: 动态相机下双手4D运动重建

> **Dyn-HaMR: Recovering 4D Interacting Hand Motion from a Dynamic Camera**
>
> **作者**: Zhengdi Yu, Stefanos Zafeiriou, Tolga Birdal (Imperial College London)
> **会议**: CVPR 2025 Highlight
> **论文**: [arXiv 2412.12861](https://arxiv.org/abs/2412.12861)
> **项目页**: [https://dyn-hamr.github.io/](https://dyn-hamr.github.io/)

## 核心贡献

首个从**动态/移动相机**拍摄的单目视频中恢复**4D 全局双手运动**的方法。与 [[HaWoR]] 同一问题域但技术路线不同——Dyn-HaMR 使用**多阶段优化**而非端到端学习。

## 方法与 [[HaWoR]] 对比

| 维度 | HaWoR | Dyn-HaMR |
|------|-------|----------|
| 手部数量 | 单手 | **双手交互** |
| 技术路线 | 解耦学习（transformer + SLAM + infiller） | **多阶段优化**（SLAM + 生成先验 + 生物力学约束） |
| 相机假设 | 静态/轻微动态 | **动态/移动相机** |
| 遮挡处理 | Motion Infiller Network | 生成式手部运动先验（HMP） |
| 交互约束 | 无 | 穿透损失、关节角约束、骨长约束、手掌曲率 |

## 方法要点

**三阶段优化管线：**

1. **Stage I — 层次化初始化**：MediaPipe + ViTPose + ACR + HaMeR 检测手部，HMP 先验生成式填充遮挡帧
2. **Stage II — 全局运动优化**：DPVO（SLAM）估计相机运动，联合优化世界尺度因子 ω、手部轨迹和相机外参，含 2D 重投影损失、平滑性约束
3. **Stage III — 交互运动先验优化**：隐编码优化 + 生物力学约束（关节角、骨长、手掌曲率）+ 穿透损失防止两手网格交叉

## 评估数据集

H2O、HOI4D、FPHA、EgoDexter、InterHand2.6M、Ego-Exo4D、HOT3D

## 思考

Dyn-HaMR 和 HaWoR 同时入选 CVPR 2025 Highlight，说明"世界坐标系手部重建"是社区关注的热点方向。两者路线互补：HaWoR 偏向学习驱动的实时性，Dyn-HaMR 偏向优化驱动的精度和物理合理性。后续 [[EgoPointVQA]] 等应用工作直接受益于此路线。
