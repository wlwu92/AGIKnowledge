# GEM — A GENeralist Model for Human MOtion (GENMO)

**ICCV 2025 Highlight** | arXiv: [2505.01425](https://arxiv.org/abs/2505.01425) | Project: [research.nvidia.com/labs/dair/gem/](https://research.nvidia.com/labs/dair/gem/)

## 概述

NVIDIA Labs 提出的统一生成式框架，同时覆盖人体运动估计（从视频/2D 关键点）与运动生成（从文本/音频），无需为不同任务设计专门的输出头。单一模型架构实现多模态输入到 SMPL 参数的端到端推理。

**License**: Apache 2.0

## 核心贡献

- **多模态条件输入**：支持视频+文本、纯视频、纯文本、2D 关键点、音频等多种输入形式
- **双能力融合**：同一模型既做运动估计（video→SMPL），又做运动生成（text/audio→SMPL）
- **实时 Webcam Demo**：完整管线 YOLOX → ViTPose-H → HMR2 → GEM denoiser，通过 ONNX Runtime 实现滑动窗口和流式全局 rollout
- **与 GEM-X 的分工**：GEM 主打运动估计+生成统一，GEM-X 专注全身（含手+脸）姿态估计，使用 [[2026-05-12-SOMA-X-统一参数化人体模型.md|SOMA]] 身体模型

## 方法机制

| 组件 | 细节 |
|------|------|
| 骨架 | PyTorch + PyTorch Lightning |
| 身体模型 | SMPL（含 GEM-SMPL 变体） |
| 训练 | AdamW (lr=2e-4), 16-mixed precision, gradient clipping 0.5, up to 500K steps |
| 图像特征 | HMR2 提取 |
| 去噪器 | GEM denoiser（扩散模型风格） |
| 多 GPU | DDP + SLURM |
| 推理加速 | ONNX Runtime |
