# 一文带你入门 3D Gaussian Splatting — 知乎

## 概述

知乎高赞文章（1,588 赞同），面向零基础读者系统讲解 3D Gaussian Splatting 的原理、数学推导和实际应用。作者为天津的一位技术博主，发布于 2024-01-31。

## 核心内容

文章从任务定义出发，逐步深入：

1. **任务背景**：三维重建 + 新视角渲染，对比 NeRF 与 传统 Mesh 方法的优劣
2. **方法动机**：解决传统方法对噪声敏感、渲染质量受限的问题
3. **核心贡献**：3D Gaussian 表示、Clone & 剪枝优化算法、快速可微渲染器
4. **方法拆解**：
   - 3D Gaussian 构建（位置、协方差、不透明度、球谐系数）
   - Splatting（抛雪球法）原理
   - 投影变换（从 3D Gaussian 到 2D splat）
   - Tile-based 可微光栅化渲染管线
5. **总体流程**：SfM 初始化 → 高斯球 → Splatting → 可微光栅化 → Loss 反向传播
6. **应用展望**：SLAM、动态场景建模、AIGC
7. **数学附录**：三维高斯分布、球谐函数、投影变换等

## 适用边界

- **不适合**：需要最新方法综述或特定实现细节的进阶读者
