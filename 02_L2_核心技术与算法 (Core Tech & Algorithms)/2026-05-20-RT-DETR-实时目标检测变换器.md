# RT-DETR — 实时目标检测变换器系列

## 概述

RT-DETR (Real-Time DEtection TRansformer) 是由 BaiDu / PaddlePaddle 团队提出的 DETR 系列实时目标检测器，论文 "DETRs Beat YOLOs on Real-time Object Detection" 发表于 CVPR 2024。RT-DETRv4 是该系列的最新迭代，利用视觉基础模型的知识蒸馏进一步提升性能，arXiv 论文 "RT-DETRv4: Painlessly Furthering Real-Time Object Detection with Vision Foundation Models"（arXiv: 2510.25257）。

相关仓库：[[lyuwenyu/RT-DETR](https://github.com/lyuwenyu/RT-DETR)]（原版）、[[RT-DETRs/RT-DETRv4](https://github.com/RT-DETRs/RT-DETRv4)]（v4 版）

## 核心贡献

- **首个在实时速度下超越 YOLO 的 DETR 检测器**，证明 Transformer 检测器可以达到 CNN 的速度水平
- **RT-DETRv4 引入 VFM 蒸馏框架**：提出 Deep Semantic Injector (DSI) 和 Gradient-guided Adaptive Modulation (GAM)，在不增加推理开销的前提下提升精度

## 方法机制

**RT-DETR（原版）**：
- 基于 DETR 架构的实时优化，引入高效混合编码器和解耦解码器设计
- 支持 ResNet、HGNetv2、RegNet 等多种骨干
- 提供 PaddlePaddle 和 PyTorch 双框架实现

**RT-DETRv4**：
- 以 DINOv3 ViT-B/16 作为教师模型，蒸馏轻量学生检测器
- **Deep Semantic Injector (DSI)**：将 VFM 高层语义注入检测器深层
- **Gradient-guided Adaptive Modulation (GAM)**：基于梯度范数比动态调节蒸馏强度
- **零额外推理开销**：所有增益来自训练阶段，部署时无需修改

## 判断与局限

- 原版 RT-DETR 成功弥合 DETR 与 YOLO 之间的 latency-accuracy gap
- RT-DETRv4 的蒸馏方案具有通用性，但依赖 DINOv3 等大型教师模型，训练时需要额外资源
- 四代演进体现了 DETR 系列的实用化路线：原版 → 加速 → VFM 增强
